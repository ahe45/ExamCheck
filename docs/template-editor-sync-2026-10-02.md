# ExamList 양식 편집기 전체 반영

- 기준: ExamList `e338f24e1e17fad5339d99f7ad2b4f246f99b53e` (2026-10-01).
- 배포 패키지: `examlist-template-editor 1.1.13-examcheck.23`.
- 원본 비교: [비교 기록](template-editor-comparison-2026-10-02.md).

## 반영 범위

기존 런타임 91개 모듈과 확장 기능을 원본 기준으로 병합하고, 공통 텍스트 편집 모듈과 HTML 정리 모듈을 추가했다. 도구 모음과 편집기 CSS도 원본과 맞췄다.

셀 너비·높이의 독립 입력, 선택과 입력 포커스 유지, 혼합값 표시, 병합 셀 계산, 확대 상태의 표·이미지 조절, 인접 행 최소 높이와 셀 안의 텍스트 선택을 반영했다. 셀 여백은 px 기준 최대 96, 소수 두 자리로 표시하며 기존 pt 저장값도 유지한다. 태그의 줄 높이와 색상 선택기의 스크롤 이동 방지도 포함한다.

선택 해제와 상호작용 중지 API를 추가했다. 페이지 번호 및 인식 기준점 설정을 현재 페이지에 연결하고 인식 기준점은 일반 문서 출력에도 반영한다.

ExamList의 인쇄 데이터 맞춤과 객체 아래 간격 보정을 ExamCheck의 브라우저 PDF·인쇄 창에 연결했다. 긴 데이터를 최소 5pt까지 축소하고, 지정된 글자 색을 보존하며 기본 글자·바코드·QR 색은 검정으로 출력한다. ExamCheck의 기존 PDF 생성 방식은 유지한다.

## 호환 처리

기존 ExamCheck 패치 .1–.22의 한글 조합 입력, 표 복사와 셀 삭제, 실행 취소·다시 실행, 날짜 태그의 개별 표시 형식, 실제 QR 생성과 문서 초과 검사 개선을 유지한다.

편집 동작 중 설정을 읽을 때 `getValue({ sync: false })`를 사용한다. 이 읽기는 문서를 다시 동기화하지 않아 선택 중인 블록과 모달을 보존한다. 데이터 블록 및 페이지 설정은 안정된 편집용 페이지에 기록하고 문서 커밋 전에 최신 페이지 설정으로 복사한다.

모달 경계 검사는 화면 확대 배율과 소수 좌표 반올림을 고려한다. 저장 HTML에 선택 핸들·모달·임시 커서 줄을 남기지 않는다.

## 패키지 재생성

```powershell
node tools/repack-template-editor.mjs
npm install --ignore-scripts
```

재생성 도구는 저장소의 .22 원본 압축 파일에 `vendor/patches/examcheck.23.patch`를 적용해 .23을 만든다. 별도의 ExamList 프로젝트 없이 재생성할 수 있다. 임시 소스는 Git에서 제외된 `.codex-tmp`에 보관한다. 메타데이터의 원본 지문은 ExamList 입력 파일, 결과물 지문은 ExamCheck 호환 변경이 포함된 파일을 나타낸다.
