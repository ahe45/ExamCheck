ExamCheck Windows 설치형 / 폴더형 사용 안내

지원 환경: Windows 10/11 x64, Microsoft Edge 또는 Chrome

설치형: ExamCheck-버전-Setup.exe를 실행하고 바탕화면의 ExamCheck 실행을 누릅니다.
폴더형: ZIP을 모두 압축 해제한 뒤 stage 폴더 안의 ExamCheck.cmd를 실행합니다.
Node.js, npm, Git, MariaDB를 사용자 PC에 따로 설치할 필요가 없습니다.
배포 폴더 전체가 필요합니다. 실행 파일만 꺼내서 사용하지 마세요.

처음 실행할 때 8자 이상의 초기 비밀번호를 두 번 입력합니다.
초기 계정은 admin / 가번호 / dev이며 처음에는 같은 비밀번호를 사용합니다.
로그인 후 계정별 비밀번호를 변경하세요.
기존 프로젝트의 데이터는 자동으로 가져오지 않습니다. 새 데이터베이스로 시작합니다.

기본 접속: http://localhost:5173
서버 관리 창을 닫으면 서버와 전용 데이터베이스가 안전하게 종료됩니다.
브라우저만 닫으면 서버는 계속 실행됩니다.
창을 닫거나 서버 종료를 누른 뒤 종료가 끝날 때까지 기다려 주세요.

다른 PC에서 사용하려면 처음 설정에서 네트워크 접속 허용을 선택합니다.
Windows 관리자 권한 요청은 방화벽 설정에만 사용합니다.
다른 PC에서는 실행 관리 창에 표시된 노트북 IP 주소로 접속합니다.
노트북과 같은 네트워크에 있어야 합니다. 공유기 격리 정책에 따라 접속이 제한될 수 있습니다.
서버용 노트북은 전원에 연결하고 사용 중 절전 모드로 들어가지 않게 설정하세요.

데이터 위치: %LOCALAPPDATA%\ExamCheck\data
백업: 서버 관리 창의 백업하기를 누르고 백업 폴더 열기로 파일을 확인합니다.
.ecbackup 파일에는 수험생 데이터와 사진 등이 포함됩니다. 다른 저장 장치에도 보관하세요.
복원: 서버를 종료한 뒤 복원하기에서 .ecbackup 파일을 선택합니다.
복원 전 현재 데이터를 자동으로 백업하며 복원 후 서버를 시작합니다.
복원은 데이터 전체를 교체하므로 복원 확인 창의 안내를 확인하세요.
백업은 데이터베이스를 대상으로 하며 PC별 브라우저 프린터 설정은 포함하지 않습니다.

업데이트: 서버 관리 창을 완전히 닫고 새 설치 파일을 실행합니다.
폴더형은 새 ZIP을 별도 폴더에 압축 해제하고 새 폴더의 ExamCheck.cmd를 실행합니다.
같은 Windows 계정의 데이터는 유지됩니다. 새 배포 버전의 첫 실행 전 자동 백업합니다.
이전 버전으로 되돌리는 작업은 별도 검증이 필요합니다.
프로그램을 제거해도 별도 데이터 폴더는 보존됩니다.

라벨 출력: 출력할 PC에서 프린터 드라이버와 Zebra Browser Print를 별도 설치합니다.
웹 화면의 프린터 설정 메뉴에서 설치 파일과 진단 기능을 사용할 수 있습니다.
일반 문서 출력만 사용할 경우 Zebra 프로그램은 필요하지 않습니다.

문제 해결: 로그 보기를 눌러 오류를 확인합니다.
포트 5173(웹), 3100(API), 13316(DB)를 다른 프로그램이 사용하면 해당 프로그램을 종료하세요.
기존 개발용 ExamCheck 서버와 설치형 서버를 동시에 실행하지 마세요.
데이터 파일이나 settings.json을 임의로 삭제하지 마세요.
